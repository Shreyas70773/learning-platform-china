### 目标

认识"浏览器代理"（Browser Agent）：一种像人一样使用浏览器、替你完成任务的 AI。它能"看见"网页（通过截图或读取页面结构），并像人一样"动手"（点击、输入、滚动）。本 Lab 用一个真实的采购任务，让你亲眼看它跑一遍。

### 准备

- 一个基于 Chromium 的浏览器（Chrome、Edge 等）
- 「Claude in Chrome」浏览器扩展（Anthropic 的测试版产品）**或者**，如果暂时用不了，就用 Lab 2 里装过的 Playwright MCP 作为"手动版浏览器代理"的替代方案
- 大约 45 分钟

> 说明：浏览器代理目前仍是前沿能力，不同工具的可用性和稳定性差别很大。如果扩展暂时无法访问，本 Lab 的"替代路径"用 Playwright MCP 一样能完成核心练习。

### 步骤

**第一步：装好浏览器代理，并理解它到底是什么**

安装「Claude in Chrome」扩展（或在 Claude Code 里确认 Lab 2 装的 Playwright MCP 仍然可用，跑 `/mcp` 确认）。

装好之后，先停下来理解一件事——**浏览器代理和你前几个 Lab 用的工具有什么本质不同**：

- API（Lab 1）拿的是结构化数据，前提是对方提供了 API
- 浏览器代理不需要对方提供 API。它直接打开网页，**像人一样看和操作**：看到搜索框就输入，看到结果就读取，看到"下一页"就点击

换句话说：**凡是人能在浏览器里做的事，浏览器代理理论上都能做**——这也是它最强、又最不稳定的地方。

**第二步：给它第一个真实的采购任务**

如果用 Claude in Chrome，打开扩展的对话框；如果用 Playwright MCP，在 Claude Code 里发下面这条消息：

```
去 1688.com，搜索 "A516 钢板"，找出排名前 5 的供应商，把他们的店铺名、主营产品、报价范围整理成一个列表。
```

**第三步：盯着它干活**

不要切走，看它一步步做：

1. 打开 1688.com
2. 在搜索框输入 "A516 钢板"
3. 浏览搜索结果，逐个读取店铺信息
4. 把店铺名、主营产品、报价整理成列表返回给你

看完之后想一个问题：**它做的这几步，和你自己手动做有什么不同？哪些地方它更快，哪些地方你会更放心？**

**第四步：再给它一个不同类型的任务**

```
去 SteelHome（钢之家）网站，找一下最新一周的中厚板市场行情，整理成一份简短的中文行情简报，包含价格区间和一句话趋势判断。
```

这次任务更"研究型"——它要在一个信息更杂的网站里找到对的栏目、读懂行情、再归纳。注意观察：它在哪一步最容易卡住或读错。

**第五步：诚实地讨论它的限制**

浏览器代理很强，但**不是万能的**。用之前要清楚它的代价：

- **慢**——它要一帧一帧地看页面、一步一步地点，比 API 慢很多
- **脆**——遇到验证码、弹窗、奇怪的页面结构，容易卡住或读错
- **贵**——每一步"看页面 + 决策"都在消耗 token
- **要盯**——重要任务不能完全放手，尤其是会"提交"或"下单"的操作

什么时候用哪个，给自己一个判断标准：

- 对方**有 API** → 优先用 API（Lab 1），又快又准
- 对方**没 API，但任务标准、重复** → 考虑 MCP / 脚本（Lab 2、Lab 3）
- 对方**没 API、页面还会变、任务更像"人工调研"** → 这时浏览器代理才真正有价值
- **高风险或不可逆的操作**（付款、下单、发送）→ 让人来做最后一步

### 检查点

完成 Lab 7 后你应该：

- 能用一句话解释浏览器代理是什么——一个会"看页面、动手操作"的 AI，像人一样用浏览器
- 至少看它完成了一个真实的采购相关任务（1688 找供应商，或 SteelHome 看行情）
- 能说清楚浏览器代理、API、MCP 各自合适的场景
- 知道哪些操作**不应该**完全交给它（高风险、不可逆的）

### 如果出错了

- 扩展用不了 / 没权限——改用 Lab 2 的 Playwright MCP 路径，核心练习一样能做
- 代理卡在某个页面——大概率是遇到了登录墙、验证码或弹窗；手动处理掉那一步，再让它继续
- 抓回来的数据不全或对不上——把任务说得更具体（"前 5 个"、"只要店铺名和报价"），范围越窄越稳
- 它想做"下单 / 提交"之类的操作——立刻停下，这类动作要人来确认

### 延伸（可选）

把浏览器代理和子代理（Lab 4）组合起来：让一个"供应商研究"子代理在研究某家供应商时，调用浏览器代理去对方店铺或官网实地看一圈，把网页上看到的信息补进研究简报里。这样你就有了一个**既能调研、又能上网实地核查**的研究流程。
